# Mój pierwszy agent — karta obserwacji

- Narzędzie i model: Antigravity IDE Claude Opus 4.6
- Moje zadanie (2–3 zdania): 
Zrobienie prostej aplikacji z przyciskiem i licznikiem ilości kliknięć oraz przyciskiem do zerowania licznika.
- Pierwsza wiadomość (wklejona co do znaku): 
Build a desktop click counter application called "clicker" with a button to zero (reset) the number of clicks.
The app will count each left mouse click on a button in the app. There needs to be a reset button that resets the number of button presses to start over. create all the necessary files. Make it in c#
